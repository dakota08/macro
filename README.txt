MACROTRACK PWA — STARTER PROJECT

WHAT'S INCLUDED
- Daily protein, carbs, and fat goals (starter values: 190g / 500g / 63g)
- Quick text entry such as "-90 carbs, -35 protein"
- Remaining macro totals and progress bars
- Undo last entry and daily history
- Edit goals and manually reset today's entries
- Local browser storage (no account or server database)
- PWA manifest and service worker for installation/offline caching

IMPORTANT NOTES
- Entries are treated as amounts consumed. A leading minus is accepted as shorthand.
- Your data is stored in this browser/device. It does not automatically sync between devices.
- Daily entries roll over when the app is opened on a new local calendar day.
- This is a starter project, not a medical or nutrition advice tool.

NEXT: PUBLISH WITH GITHUB PAGES
1. Sign in to https://github.com/ or create a free account.
2. Create a new PUBLIC repository named macrotrack.
3. On the repository page choose Add file > Upload files.
4. Unzip this folder on your computer, then drag all files INSIDE the folder into GitHub's upload area.
5. Click Commit changes.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait a minute or two. The published address will be shown on the Pages screen.
10. Open that address in Safari on your iPhone, tap Share, then Add to Home Screen.

If the app is published at a project URL ending in /macrotrack/, the included relative paths support that setup.
